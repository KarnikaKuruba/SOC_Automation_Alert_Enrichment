# SOC_Automation_Alert_Enrichment

**Purpose:** Demonstrates alert enrichment and basic automation for SOC triage.

## Contents
- `main.py` - Enrich alerts (simulate threat intel lookups) and produce JSON+CSV outputs.
- `threat_intel_api.py` - Simulated threat intel functions (replace with real API calls when available).
- `sample_alerts.json` - Sample alerts for testing.
- `results/` - Example output files generated by the script.
- `README.md` - This file.

## How to run (local environment)
1. Ensure Python 3.8+ is installed.
2. Run:
   ```bash
   python main.py sample_alerts.json results/enriched_alerts.json results/summary.csv
   ```
3. Open `results/enriched_alerts.json` and `results/summary.csv` to review results.
